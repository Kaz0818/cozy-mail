# 引き継ぎ書 — ローカル (Mac) とクラウドの作業の受け渡し

Cozy Mail は、2 つの場所で作業する。

| 場所 | 何ができるか | できないこと |
|---|---|---|
| **ローカル** (オーナーの Mac の Claude Code) | すべて。`swift test`、`xcodebuild test` (アプリ・UI テスト・SwiftData) | — |
| **クラウド** (claude.ai/code の Linux) | `Packages/` の `swift test`、コードを書く、PR、CI の macOS を手動で動かして結果を読む | SwiftData・アプリ・UI のテストを手元で動かす (CI の macOS 頼み) |

**作業を始める AI は、まずこのファイルを読む。作業を終える AI は、このファイルの「今の状況」と「作業の記録」を書き直してから終える。**

---

## 1. 受け渡しのやり方

### 始めるとき (ローカルでもクラウドでも同じ)
1. `git checkout main && git pull` で最新にする (クラウドは指定のブランチを main にそろえる)。
2. このファイルの「今の状況」と、[tasks/todo.md](../tasks/todo.md) の今のタスクを読む。
3. 作業用のブランチを作る (ローカル: 例 `swiftdata-store`。クラウド: 会話ごとに決められた `claude/...`)。

### 終えるとき
1. テストとビルドを通す ([CLAUDE.md](../CLAUDE.md) の「コマンド」)。
2. tasks/todo.md と tasks/plan.md のチェックを更新する (🍎 はオーナーが確認してから)。
3. **このファイルの「今の状況」と「作業の記録」を書き直す。** 次の人が最初に何をすればよいか分かるように。
4. コミット → プッシュ → 下書きの PR。オーナーがマージする。
5. マージされるまで、もう一方の場所では同じところを触らない。

### 守ること
- **ローカルとクラウドで、同時に同じブランチを触らない。** 受け渡しは、いつも main を通す (PR をマージしてから次へ)。
- まだマージしていない作業を、もう一方に渡したいときは、ブランチ名をこのファイルに書く。
- クラウドで SwiftData やアプリの画面のコードを変えたときは、CI の macOS を手動で動かして、結果を報告に書く。

### 次の人がやること: T10 を SwiftData で作る (ローカル)
1. `Packages/MailStore` に **Apple 専用のターゲット** `MailStoreSwiftData` を足し、`SwiftDataMessageStore` を作る。
   - `MailStore` 本体には SwiftData を入れない (Linux の CI が壊れるため)。キーチェーンの `AccountKitKeychain` と同じ分け方。
   - `MessageStore` プロトコルのすべての操作を実装する (メール・同期の進み具合・未読数・フォルダ名・開いたメールの生データ)。
   - 生データ (本文と添付) は大きいので、データベースの外のファイルに置くか、`@Attribute(.externalStorage)` を使う。
2. テストを先に書く。参考ブランチ `claude/file-message-store` の `FileMessageStoreTests.swift` (10 件) を流用できる:
   保存 → 開き直す、上書き、削除で生データも消える、フォルダの全削除、アカウント削除、開き直したあとの同期は新しいメールだけ。
   SwiftData のテストは `swift test --package-path Packages/MailStore` (Mac) で動く。CI では macOS のジョブで動くように `ci.yml` に足す。
3. `App/Services/MailService.swift` の `live()` で `InMemoryMessageStore` と差し替える。作れなかったときはメモリ上に戻す。
   UI テスト (`-ui-testing`) とプレビューはメモリ上のまま。
4. SPEC.md の「Mac 内の保存」と、tasks/todo.md・plan.md の T10 を直す。
5. 🍎 オーナーに確認してもらう: 起動 → メールを開く → 終了 → もう一度起動すると、すぐに一覧が出て、開いたメールがすぐ表示される。

### このあとの作業の場所の目安
- **ローカル向き**: 保存先・画面・アプリ全体に関わるもの (T10、T13、T19、T21 メニューバー、T22 オフラインの待ち行列、T23 下書き、T24 送信の取り消し)。
- **クラウドでもできる**: `MailCore` だけで済むもの (T20 IMAP IDLE の受信部分、T27 サーバー側の検索の命令、MIME の改良)。
- 迷ったらローカル。クラウドに戻る必要は必ずしもない。オーナーが Mac から離れているとき (スマホからなど) に、クラウド向きの作業を進める。
