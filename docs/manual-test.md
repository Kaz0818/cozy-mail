# 手で確かめる手順書 (チェックポイント v0.1)

v0.1 で「実際に使える」かを、オーナーが Mac で確かめるための手順。SPEC の P0 のユーザーストーリー (US-1〜US-11) に沿っている。
自動テストで確かめられることは、ここには入れていない (テストの件数は [CLAUDE.md](../CLAUDE.md))。

- 使うもの: `~/Applications/Cozy Mail.app`、Gmail の Web 版 (ブラウザ)、自分のアカウント。
- 確かめたら □ を ☑ にして、うまくいかなかったことは「メモ」に書く。Claude が tasks/todo.md の 🍎 にチェックを付ける。
- **メールを送る・消す手順は、自分宛てのメールだけで行う。**

## 0. 始める前に

- □ PR を番号の小さい順にマージした (#11 → #12)。Claude がアプリを作り直して `~/Applications` に置いた。
- □ アプリを起動すると、キーチェーンの確認が出ない (出たら「常に許可」を押す)。

## 1. アカウント (US-1、US-2)

- □ 設定 (⌘,) のアカウントに、Gmail 3 つが並んでいる。
- □ (新しく足すときだけ) メールアドレスとアプリパスワードを入れると、30 秒以内に受信トレイが出る。
- □ Yahoo! (アドレスを持ったときに): アドレスとアプリパスワードだけで足せて、受信トレイが出る。

## 2. 統合受信トレイと絞り込み (US-3、US-4、US-9)

- □ 「すべての受信トレイ」に、全アカウントのメールが新しい順に並び、各行にどのアカウントかの印がある。
- □ 未読数: サイドバーの各アカウントの数が、Gmail の Web 版の受信トレイの未読数と同じ。
- □ サイドバーでアカウントを選ぶと、そのアカウントのメールだけになる。フォルダ (送信済み・アーカイブなど) を選ぶと切り替わる。
- □ 各フォルダの件数が Web 版と同じ (最近 30 日より前のメールは保存していないので、その分は除く)。
- □ 「すべて / 未読 / スター付き」で絞れる。
- □ ラベル: Web 版でテスト用のラベル (例「テスト」) を作ってメールに付け、Cozy Mail で受信 (⇧⌘N) → アカウントを選ぶと「ラベル」に出て、選ぶとそのメールが出る。確かめたらラベルは消してよい。
- □ アプリを閉じて開き直すと、前回の一覧がすぐ出て、開いたことのあるメールは本文もすぐ出る。
- ✗ Dock のアイコンの未読数は、まだ作っていない (T20 で作る予定。下の「まだのこと」)。

## 3. 読む (US-5)

- □ HTML のメール (お店のお知らせなど) が崩れずに出る。外部の画像は「画像を表示」を押すまで出ない。
- □ 添付ファイルをダブルクリックすると Quick Look で見える。保存ボタンで Finder に保存できる。
- ✗ 添付ファイルを Finder へドラッグすることは、まだできない。

## 4. 書く・送る (US-6) — 自分宛てで

- □ ⌘N で作成ウィンドウが開き、差出人のアカウントを選んで、宛先・件名・本文・添付を入れて ⌘↩ で送れる。届く。
- □ 届いたメールに ⌘R で返信すると、受け取ったアカウントから送られる。「送信済み」に 1 通だけ入る。
- □ ⇧⌘R (全員に返信)、⇧⌘F (転送) も開く。

## 5. 整理する (US-7、US-8) — 自分宛てのメールで

- □ 既読/未読・スター・アーカイブ・削除・迷惑メールが、ツールバーのボタン・右クリックのメニュー・キーボードでできて、すぐ画面に出る。
- □ 同じ操作が、少しして Gmail の Web 版にも出る。
- □ キーボード: ↑ ↓ (J K) で前後のメール、E でアーカイブ、⌫ で削除、⌘F で検索欄。メニューバーの「メッセージ」にも並んでいる。

## 6. 検索 (US-10)

- □ ⌘F で検索欄に移り、知っている差出人の名前・アドレスの一部、件名の一部を入れると、そのメールが出る (日本語でも)。見出しが「検索」になる。
- □ 言葉を 2 つ空白で区切ると、両方を含むメールだけになる。
- □ esc か欄の × で、元の一覧に戻る。
- □ Wi-Fi を切っても検索できる。
- △ 本文で探せるのは、開いたことのあるメールの本文の書き出し (約 140 文字) まで。本文全体で探すかは相談 ([docs/handoff.md](handoff.md) の「オーナーの確認待ち」)。

## 7. 見た目 (US-11、チェックポイント v0.0)

- □ 設定の「ライト / ダーク / システムに合わせる」を切り替えると、すぐ変わる。
- □ アプリの画面を見本の 2 枚と並べて、「ほぼ同じ」と言える。
